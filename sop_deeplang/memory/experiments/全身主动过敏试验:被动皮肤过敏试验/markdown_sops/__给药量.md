### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据或偏离的章节场景。撰写时必须遵守以下规则：  
- 确认无任何试验数据、偏差或分析结果可报告。  
- 使用简洁声明确认合规性，不引入任何假设或额外细节。  
- 若后续输入出现数据，则切换至数据驱动模式；否则，保持声明式表述，确保报告逻辑闭环（无数据 = 无偏离）。  
- 避免任何计算或比较，仅报告状态确认。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入附件或记录：若无试验数据、偏差或结果，则直接使用模板语句。  
2. 填充占位符：`{{Study_ID}}` 为试验编号；`{{Section_Name}}` 为章节名称。  
3. 输出格式：纯文本声明，无表格或图表。  

**模板语句**：  
在本 `{{Section_Name}}` 章节中，试验 `{{Study_ID}}` 无任何数据记录或偏离。所有操作符合 GLP 要求，无需进一步分析。

### **第三部分：报告示例**
在本 Stability 章节中，试验 XYZ-001 无任何数据记录或偏离。所有操作符合 GLP 要求，无需进一步分析。
