### **第一部分：核心准则**
由于提供的验证方案（Protocol）和GLP报告（Report）内容为空，本章节无具体接受标准或数据呈现逻辑。撰写时必须遵守GLP通用原则：仅在有明确数据支持时报告细节；若无数据或偏离，则以简洁声明形式表述“无偏离”或“未执行”，确保报告逻辑闭环，不引入未验证的假设。动态数据（如试验编号、日期）若存在，应直接从原始记录提取；否则，使用声明式描述。

### **第二部分：通用模板**
1. 检查原始记录中是否存在与本章节相关的试验数据或偏离事件。
2. 若无数据或偏离：使用以下模板语句填充报告：
   - “本章节验证未执行{{Specific_Test}}，或无偏离事件。[试验编号]：{{Trial_ID}}，日期：{{Test_Date}}。”
3. 若存在数据：提取关键变量（如{{Key_Metric}}），计算{{Calculation_Step}}（保留2位小数），并对比接受标准{{Acceptance_Criteria}}，描述结果。
4. 结束时添加声明：“所有操作符合GLP要求，无未报告偏离。”
