### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据或偏离的章节场景。撰写时必须遵守以下规则：  
- 确认无任何试验数据、接受标准或偏差记录存在。  
- 报告内容限于声明性表述，不引入任何假设或额外细节。  
- 若后续输入出现数据，则切换至动态计算逻辑；否则，保持简要声明。  
- 逻辑闭环：直接声明“无偏离”或“未执行”，避免任何量化描述。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入附件或记录中是否包含该章节相关数据（如试验结果、偏差日志）。  
2. 若无数据，填入模板：  
   “本章节[{{章节名称}}]无试验执行记录或偏差发生。所有操作符合GLP标准，无偏离。”  
3. 若有数据，提取关键变量（如{{试验编号}}、{{偏差描述}}），并对比协议标准生成判定；否则，直接输出声明。  
4. 结束时添加： “结论：合规，无需进一步行动。”

### **第三部分：报告示例**
本章节[系统适用性测试]无试验执行记录或偏差发生。所有操作符合GLP标准，无偏离。  
结论：合规，无需进一步行动。
