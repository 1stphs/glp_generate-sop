### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据或偏离的章节撰写。核心原则为：采用声明式表述，确认无偏差或数据缺失情况；不引入任何假设性计算或外部数据；若未来输入数据，则优先提取实际值对比协议标准（若协议为空，则默认“无偏离”）；保持简洁、中性商务语气，避免推测性语言。

### **第二部分：通用模板**
1. 确认输入：检查验证方案和报告原始记录。若无具体数据或偏离，执行声明模式。
2. 提取变量：使用占位符如 {{试验编号}}、{{章节名称}} 表示任何潜在动态元素（若无，则省略）。
3. 撰写指令：
   - 开头声明： "{{章节名称}} 章节执行符合 GLP 要求，无偏离或数据缺失。"
   - 若有数据： "从附件 {{附件编号}} 提取 {{数据类型}}（例如：{{实际值}}），对比方案标准 {{接受标准}}，结果为 {{判定结果}}。"
   - 结尾总结： "本章节验证完成，无需进一步行动。"
4. 格式要求：使用标准报告段落结构，字体 Arial 11，单倍行距。

### **第三部分：报告示例**
试验编号：GLP-001  
章节名称：通用验证章节  

本章节执行符合 GLP 要求，无偏离或数据缺失。所有操作基于标准协议完成，结果满足预期，无需进一步行动。
