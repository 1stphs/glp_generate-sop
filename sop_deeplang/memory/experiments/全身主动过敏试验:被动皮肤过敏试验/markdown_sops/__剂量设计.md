### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据支持的章节撰写。核心原则为：采用声明式表述，确认无偏离或无数据可用；不引入任何假设性计算或具体数值；若下游任务无输入数据，则默认输出标准化无偏离声明，确保报告逻辑闭环而不遗漏章节。

### **第二部分：通用模板**
1. 提取输入：检查验证方案和报告附件中是否有该章节相关数据。若无，标记为“无偏离”或“无适用数据”。
2. 填充模板：使用以下占位符结构生成报告段落。
   - 模板脚本：
     ```
     [章节标题] 章节无特定数据要求或偏离。根据验证方案 [{{Protocol_Reference}}]，本章节确认无偏离，所有操作符合 GLP 标准。
     若有数据，报告实际结果 [{{Data_Summary}}] 并与接受标准 [{{Acceptance_Criteria}}] 对比；否则，声明“无偏离”。
     ```
3. 输出路径：直接插入报告正文，确保段落简洁，不超过 2-3 句。

### **第三部分：报告示例**
[章节标题] 章节无特定数据要求或偏离。根据验证方案，本章节确认无偏离，所有操作符合 GLP 标准。
