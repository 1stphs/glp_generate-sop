### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据或偏离的章节场景。核心准则为：若章节无试验数据支持，下游 AI 必须生成简明声明，确认“无偏离、无数据记录”，并确保表述符合 GLP 合规性（客观、中性、无推测）。禁止添加任何假设性内容或计算逻辑。若未来输入有数据，则切换至数据提取与对比模式。

### **第二部分：通用模板**
执行以下指令生成报告片段：
1. 检查输入 Protocol 和 Report 是否为空。
2. 若为空或仅含声明（如“无偏离”），使用模板：  
   “本章节[章节名称]验证基于[试验编号]，无试验数据记录或偏离。所有操作符合 GLP 要求，无需进一步计算或分析。”
3. 替换占位符：`[章节名称]`（如“系统适用性”）、`[试验编号]`（若有，否则用“N/A”）。
4. 输出纯文本，无额外解释。

### **第三部分：报告示例**
本章节系统适用性验证基于试验编号 GLP-001，无试验数据记录或偏离。所有操作符合 GLP 要求，无需进一步计算或分析。
