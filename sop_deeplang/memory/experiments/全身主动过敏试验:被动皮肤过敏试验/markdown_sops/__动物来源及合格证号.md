### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，且无具体章节名称指定，撰写时必须遵守以下基础规则：  
- 在无数据支持的情况下，生成简短的声明式描述，确认章节未执行或无偏差。  
- 避免引入任何具体数值或假设数据；使用占位符表示潜在变量（如 {{Chapter_Name}}）。  
- 确保输出逻辑闭环：直接声明“无偏差”或“未适用”，无需计算或比较步骤。  
- 对于下游 AI 执行，指令必须包含分支：若未来输入数据，则扩展为数据提取与描述；否则，保持声明式。

### **第二部分：通用模板**
执行以下指令生成 {{Chapter_Name}} 章节内容：  
1. 检查输入的验证方案 (Protocol) 和报告 (Report) 是否为空。  
   - 如果为空或仅含声明（如“无偏差”），输出：  
     “在 {{Chapter_Name}} 章节中，未执行特定验证或无相关数据记录。试验符合 GLP 要求，无偏差。”  
   - 如果存在数据，从 Protocol 提取接受标准（如 {{Acceptance_Criteria}}），从 Report 提取实际结果（如 {{Actual_Results}}）。  
2. 比较 {{Actual_Results}} 与 {{Acceptance_Criteria}}：  
   - 若符合，添加描述：“结果满足预设标准。”  
   - 若不符合，添加描述：“存在偏差，详见偏差记录 [参考偏差编号]。”  
3. 格式化为标准报告段落，确保商务语气中性、专业，不超过 3 句。
