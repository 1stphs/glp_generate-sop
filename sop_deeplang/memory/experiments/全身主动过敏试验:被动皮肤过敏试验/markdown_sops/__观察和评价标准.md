### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空，且无上一版本 SOP 作为参考，本 SOP 采用声明式模式处理无数据章节。核心准则为：当章节无具体数据、偏离或计算要求时，下游 AI 必须生成简洁的合规声明，确认“无偏离、无异常”，并引用通用 GLP 原则（如数据完整性）。严禁编造任何具体数值或假设场景；若未来输入数据出现，则切换至动态数据提取与对比逻辑（例如，检查是否符合预设接受标准，如差异 ≤ ±15.0%）。输出必须保持客观、中性商务语气，避免任何主观解释。

### **第二部分：通用模板**
1. **数据检查步骤**：审阅附件或原始记录，确认该章节无试验数据、无偏离事件。若存在数据，提取关键变量（如 {{Test_ID}}、{{Measured_Value}}、{{Acceptance_Criteria}}），计算必要指标（例如，均值 = SUM({{Raw_Data}})/N，CV% = (SD/Mean) × 100，保留两位小数）。
2. **合规判定**：若无数据，输出标准声明：“本章节无试验执行记录或偏离事件，符合 GLP 要求。” 若有数据，对比 {{Measured_Value}} 与 {{Acceptance_Criteria}}；若符合，添加“结果满足接受标准”；若不符合，标记“存在偏离，详见偏差管理部分”并计算偏差率（{{Deviation}} = |{{Measured_Value}} - {{Expected_Value}}| / {{Expected_Value}} × 100）。
3. **填充指令**：使用以下模板生成文本：
   - 开头： “章节 [{{Chapter_Name}}] 验证结果如下：”
   - 主体： “无具体数据记录 / [{{Calculated_Result}}]，{{Compliance_Statement}}。”
   - 结尾： “所有操作符合 GLP 规范，无未解决偏差。”
