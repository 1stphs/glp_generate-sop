### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空，且无具体章节内容指定，本 SOP 适用于无数据或无偏离的通用声明章节。撰写时必须遵守以下规则：  
- 确认无具体试验数据或偏离事件时，直接声明合规状态，避免任何数据提取或计算步骤。  
- 表述必须简洁、客观，使用标准商务语气，确保逻辑闭环（声明事实 → 确认合规 → 无进一步行动）。  
- 不引入任何假设性内容；若未来有数据输入，则切换至动态模板，但当前仅处理静态声明。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入材料（Protocol 和原始记录）：若无试验数据、偏离或具体事件，直接使用静态声明。  
2. 填充占位符：`[章节名称]` 为当前章节标题；`[试验编号]` 为适用试验 ID（若无，则省略）。  
3. 输出格式：以段落形式呈现，确保不超过 2-3 句。  

**模板脚本**：  
“在 [章节名称] 中，试验编号 [试验编号] 的执行符合验证方案要求，无任何偏离或异常事件发生。所有操作均按照 GLP 原则进行，无需进一步数据分析或修正。”
