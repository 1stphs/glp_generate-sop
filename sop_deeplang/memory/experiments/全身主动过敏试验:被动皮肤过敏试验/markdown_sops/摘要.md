### **第一部分：核心准则**
由于验证方案 (Protocol) 和 GLP 报告 (Report) 中均无具体内容或数据，本章节撰写时必须遵守声明式原则：仅在无偏离、无数据或空章节情况下，使用标准化声明确认合规性，不引入任何假设性计算、阈值或动态变量；若未来有输入，则扩展为数据驱动描述，但当前保持最小表述以确保 GLP 逻辑闭环。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查验证方案 (Protocol) 和 GLP 报告 (Report) 输入是否为空或仅含声明（如“无偏离”）。  
2. 若为空或无具体数据，输出标准化声明：`本章节[{{章节名称}}]无偏离或具体数据记录，符合 GLP 要求。`  
3. 若有数据，替换占位符：从 Protocol 提取接受标准（若无，则用 `{{无指定标准}}`），从 Report 提取实际结果（若无，则用 `{{无数据}}`），并描述：`根据验证方案[{{Protocol_引用}}]，实际结果[{{Report_数据}}]符合标准[{{Acceptance_Criteria}}]。`  
4. 确保输出精简，不添加额外解释。

### **第三部分：报告示例**
本章节[章节名称]无偏离或具体数据记录，符合 GLP 要求。
