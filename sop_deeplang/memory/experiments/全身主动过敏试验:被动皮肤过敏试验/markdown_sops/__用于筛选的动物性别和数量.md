### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据支持的章节场景。撰写时必须遵守以下规则：  
1. 确认章节无任何试验数据、偏离或计算需求，仅需声明合规状态。  
2. 使用标准化声明句，避免任何数据引用或假设性描述。  
3. 若下游输入出现数据，则切换至动态评估逻辑（例如，提取实际值并与预设标准对比）；否则，默认输出“无偏离”表述。  
4. 保持 GLP 报告的客观性和简洁性，不引入未验证的信息。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入附件或记录中是否包含该章节的具体数据（如试验结果、偏差记录）。  
2. 如果无数据：直接输出模板声明“[章节名称] 未发生任何偏离，所有操作符合验证方案要求。”  
3. 如果存在数据：从附件提取关键变量（如 {{Deviation_Type}} 和 {{Measured_Value}}），计算是否符合预设标准（例如，{{Deviation_Type}} ≤ {{Acceptance_Criterion}}），然后填充分支描述：  
   - 符合："[章节名称] 结果为 {{Measured_Value}}，符合接受标准，无偏离。"  
   - 不符合："[章节名称] 结果为 {{Measured_Value}}，超出接受标准 {{Acceptance_Criterion}}，偏离已记录并评估影响。"  
4. 结束时添加“详见附件 [Attachment_ID] 以获取原始记录。”

### **第三部分：报告示例**
**章节名称：系统适用性测试**  
系统适用性测试未发生任何偏离，所有操作符合验证方案要求。详见附件 1 以获取原始记录。
