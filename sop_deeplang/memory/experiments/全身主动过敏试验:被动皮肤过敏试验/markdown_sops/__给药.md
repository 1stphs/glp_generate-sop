### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据或偏离的章节，定义最小合规表述规则：  
- 静态文本直接声明“本章节无试验数据或偏离”，无需动态计算或数据提取。  
- 确保表述简洁、中性，避免任何假设或补充信息。  
- 若未来有数据输入，优先从附件或原始记录提取变量（如试验编号），但当前仅输出标准声明。  
- 合规底线：所有输出必须基于 GLP 原则，声明事实而非推断。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入方案和报告是否为空白或仅含声明（如“无偏离”）。  
2. 若为空白或无数据，填入以下模板：  
   “本章节[章节名称]无具体验证方案或试验数据支持。经审查，无任何偏离或异常记录。{{试验编号}}（若适用）符合 GLP 要求。”  
3. 若有数据，替换占位符：从原始记录提取{{试验编号}}、{{数据变量}}，并插入动态描述；否则，保持静态声明。  
4. 输出格式：纯文本段落，无表格或额外解释。

### **第三部分：报告示例**
本章节无具体验证方案或试验数据支持。经审查，无任何偏离或异常记录。试验编号 GLP-001 符合 GLP 要求。
