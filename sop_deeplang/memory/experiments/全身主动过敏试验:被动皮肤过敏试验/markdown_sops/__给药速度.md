### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据支持的章节场景。撰写时必须遵守以下规则：  
- 确认章节无试验数据、偏离或分析结果，仅需声明合规状态。  
- 判定逻辑：若无输入材料支持，则默认表述为“本章节无偏离或数据记录”，避免任何假设性描述。  
- 通用化处理：使用占位符标记试验上下文（如 {{试验编号}}），确保输出简洁且不引入未验证信息。  
- 分支逻辑：若后续输入出现数据，则扩展为“静态声明 + 动态提取”；否则，保持声明式表述。

### **第二部分：通用模板**
执行以下指令生成报告章节：  
1. 检查输入材料（Protocol 和 Report 数据源）：若为空白或仅含标题，跳过数据提取，直接使用声明模板。  
2. 填充占位符：替换 {{章节名称}} 为实际章节标题，{{试验编号}} 为试验标识。  
3. 输出结构：  
   - 开头声明：{{章节名称}} 部分无具体试验数据或偏离记录。  
   - 合规模板：本章节符合 GLP 要求，无需进一步分析。  
   - 结束语：参考 Protocol {{试验编号}}，所有操作已按标准执行。  
4. 若有数据输入（未来分支）：从附件提取关键指标，计算 {{指标值}}（保留 1 位小数），并对比标准阈值 {{阈值}}；若符合，添加“结果满足接受标准”。
