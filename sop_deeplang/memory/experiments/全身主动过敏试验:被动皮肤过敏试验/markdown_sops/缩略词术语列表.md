### **第一部分：核心准则**
在 GLP 报告的缩写与术语章节中，必须严格遵守 GLP 指南（OECD 和 NMPA 标准），列出所有在报告中使用的缩写，确保每个缩写对应唯一的英文全称和中文全称。表格格式必须采用标准三列表格（缩写、英文全称、中文全称），无遗漏、无重复，且仅包含报告中实际出现的术语。准则优先级：完整性（覆盖所有关键实体，如公司、监管机构、流程）、准确性（全称基于官方定义）、简洁性（无额外解释）。

### **第二部分：通用模板**
1. 从报告全文扫描所有缩写，确保列表覆盖公司名称（e.g., InnoStar）、监管机构（e.g., NMPA, FDA, OECD）、GLP 相关术语（e.g., GLP, QA, SOP, QAU）、文件类型（e.g., COA）。  
2. 构建 Markdown 表格格式：第一行表头为 "| 缩写 | 英文全称 | 中文全称 |"，后续行填充数据，使用官方标准全称。  
3. 如果报告中无新增缩写，复用标准 GLP 缩写表；若有偏差，标记为 [新增/更新] 并在表格后注明来源（e.g., 从 COA 或 SOP 提取）。  
4. 插入占位符 [Company_Name]、[Regulatory_Body] 等，确保表格动态适配不同报告版本。  
示例指令执行路径：扫描报告 -> 提取缩写 -> 验证全称准确性 -> 生成表格 -> 置于报告开头或附录。
