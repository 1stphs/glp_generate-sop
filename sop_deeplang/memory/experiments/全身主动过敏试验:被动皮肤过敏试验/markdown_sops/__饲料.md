### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据或偏离的章节场景。撰写时必须遵守以下规则：  
- 确认无试验数据、无偏离事件或无额外要求时，使用标准化声明句，避免任何具体数值或假设计算。  
- 动态部分（如章节适用性）通过占位符标记，例如 `[章节名称]` 或 `[试验编号]`，确保通用性。  
- 若下游输入出现数据，则扩展为“数据提取-描述”流程；否则，保持简短声明。  
- 逻辑闭环：检查协议中是否提及“无偏离”，若有，则直接映射为报告声明；无协议支持时，输出中性表述。

### **第二部分：通用模板**
**指令脚本**（供 AI Generator 执行）：  
1. 检查输入协议 [Protocol_ID] 和报告样本 [Report_ID] 是否为空或仅含声明（如“本章节无偏离”）。  
2. 若为空/无数据：填入模板 - “在 [章节名称] 章节中，未记录任何试验数据或偏离事件，符合 GLP 要求，无需额外计算或分析。”  
3. 若有数据：从附件 [Data_Source] 提取关键变量（如 {{Key_Metric}}），计算 {{Calculation_Step}}（保留 2 位小数），对比协议阈值 {{Acceptance_Criteria}}，生成描述：  
   - 符合：{{Key_Metric}} = {{Value}}，满足 {{Acceptance_Criteria}}。  
   - 不符合：{{Key_Metric}} = {{Value}}，超出 {{Acceptance_Criteria}}，需说明原因。  
4. 结束：添加“本节结论：{{Summary_Statement}}”。

### **第三部分：报告示例**
