### **第一部分：核心准则**
由于验证方案（Protocol）和GLP报告（Report）中无具体内容提供，本章节撰写时必须遵守以下底线：若无任何数据或偏离信息，直接声明“本章节无偏离或特定数据”，确保表述简洁、合规，不引入未验证的假设或额外细节。动态部分（如试验编号）需使用占位符替换，静态声明保持通用化。无计算需求时，跳过数据提取步骤，仅输出标准声明。

### **第二部分：通用模板**
1. 检查验证方案和报告中是否包含[章节名称]的具体数据或偏离描述。  
2. 若无数据或偏离，直接填入以下模板：  
“[章节名称]：本章节无偏离或特定数据记录，符合验证方案要求。”  
3. 若存在数据，从原始记录提取关键变量（如{{Trial_ID}}、{{Data_Value}}），计算或对比后描述；否则，使用上述声明。  
4. 确保输出不添加额外解释，保持商务语气。
