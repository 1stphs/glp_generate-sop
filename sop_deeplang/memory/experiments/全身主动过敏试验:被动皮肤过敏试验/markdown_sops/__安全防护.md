### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据或偏离的章节（如通用声明章节）制定准则：  
- 仅在无试验数据或偏离时，使用标准化声明确认合规性。  
- 静态文本直接复制方案中的通用声明（如“本章节无偏离”）；动态部分（如试验编号）使用占位符填充。  
- 若未来输入数据，优先提取实际记录进行描述；否则，默认输出“无偏离”以确保逻辑闭环。  
- 保持简洁商务语气，长度不超过 50 字，避免任何计算或分支判定。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入方案中是否有特定声明；若无，使用默认静态文本：“本章节无偏离，所有操作符合 GLP 要求。”  
2. 插入动态占位符：如试验编号为 `{{Trial_ID}}`，日期为 `{{Test_Date}}`。  
3. 输出模板：  
   “[章节名称] 验证结果：{{Trial_ID}} 于 {{Test_Date}} 完成，无任何偏离或数据记录。所有步骤符合预定方案。”  
4. 若有数据输入，替换为实际提取值；否则，直接应用默认声明。

### **第三部分：报告示例**
[章节名称] 验证结果：Trial-001 于 2023-10-01 完成，无任何偏离或数据记录。所有步骤符合预定方案。
