### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，且无章节名称指定，本 SOP 适用于 GLP 文档中无具体数据或偏离的通用声明章节。撰写时必须遵守以下规则：  
1. 确认无任何偏差或数据输入时，使用标准化声明句，避免引入任何假设性内容。  
2. 保持客观、中性语气，仅报告“无偏离”事实，不添加计算、比较或分支逻辑。  
3. 动态部分（如试验编号）使用占位符替换，确保模板通用性。  
4. 若未来输入有数据，SOP 需扩展为数据提取-验证流程；当前限于声明模式。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入 Protocol 和 Report 是否为空或仅含“无偏离”声明。  
2. 若确认无数据/偏差，从 Protocol 提取通用试验标识（如 {{Trial_ID}}），否则使用默认“本试验”。  
3. 填充以下模板文本，无需计算或数据插入：  
   “在 {{Trial_ID}} 的本章节验证中，未观察到任何偏差或不符合接受标准的情况。所有程序均按照批准的方案执行。”  
4. 输出时确保商务正式格式：段落独立，无 bullet points。

### **第三部分：报告示例**
在 GLP-001 的本章节验证中，未观察到任何偏差或不符合接受标准的情况。所有程序均按照批准的方案执行。
