### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据支持的章节（如通用声明章节）制定准则：  
- 严格遵守 GLP 原则，在无试验数据、偏离或具体操作记录时，报告必须以简洁声明形式呈现，确认章节适用性并注明“无偏离”或“未执行”。  
- 区分静态声明（固定文本，如章节标题确认）和动态部分（若未来有数据，则需提取试验编号、日期等变量）。  
- 若无数据，禁止引入任何计算或比较逻辑；仅输出合规确认语句。  
- 确保报告语言正式、中性，避免推测性描述；若有分支（如未来数据不符合标准），需添加判定语，但当前默认为合规状态。

### **第二部分：通用模板**
**执行指令**：  
1. 检查输入：若验证方案和报告数据为空或仅含声明，确认章节为“无具体执行”类型。  
2. 提取静态文本：直接复制章节标题或通用声明（如“本章节符合 GLP 要求”）。  
3. 填充动态插槽：使用占位符标记潜在变量，例如 [章节名称]、[试验编号]、[日期]。若无数据，填充为“未执行”或“N/A”。  
4. 生成报告文本：  
   “章节 [章节名称] 已审阅验证方案与报告记录。{{试验编号}} 于 {{日期}} 执行，无偏离或数据记录。所有操作符合 GLP 标准。”  
5. 分支逻辑：若未来输入数据不符合标准，添加“存在偏离：{{偏离描述}}，已评估影响”并建议纠正措施；否则，默认“无偏离”。  
6. 格式要求：使用正式商务语气，段落简洁，不超过 3 句；置于报告相应位置。

### **第三部分：报告示例**
章节 [系统适用性测试] 已审阅验证方案与报告记录。试验编号 GLP-001 于 2023-10-15 执行，无偏离或数据记录。所有操作符合 GLP 标准。
