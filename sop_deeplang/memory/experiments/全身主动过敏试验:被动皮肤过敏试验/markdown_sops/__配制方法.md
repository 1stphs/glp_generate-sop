### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无明确数据支持的章节场景。撰写时必须遵守以下规则：  
1. 确认章节无具体实验数据或偏离记录，仅需声明合规状态。  
2. 表述限于事实性陈述，不引入任何假设或额外解释。  
3. 若下游输入出现数据，则切换至数据提取与描述逻辑；否则，使用通用声明模板。  
4. 保持 GLP 合规：所有声明必须基于可追溯的空记录状态，无需计算或比较。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入附件中 [章节名称] 是否有数据记录（如 [数据类型，例如：测试结果、日期]）。  
2. 若无数据：输出标准化声明，使用占位符替换具体章节。  
   - 模板：  
     "章节 [章节名称]：本章节无实验数据或偏离记录。所有操作符合 GLP 要求，无需进一步评估。"  
3. 若有数据：从 [附件位置，例如：Table X 或 Raw Data Y] 提取 [关键变量，例如：Mean 值、CV%]，计算 [简单统计，例如：平均值 = SUM(数据)/N，保留 1 位小数]，并与 [接受标准，例如：±{{Threshold}}] 比较。若符合，添加确认句；若不符合，标记为 [偏差描述]。  
   - 模板：  
     "章节 [章节名称]：从 [数据源] 提取数据 [{{Extracted_Data}}]。计算结果 [{{Calculated_Result}}] 符合接受标准 [{{Acceptance_Criteria}}]。无偏离。"  
4. 结束时添加： "本章节结论：合规。"

### **第三部分：报告示例**
章节 [章节名称]：本章节无实验数据或偏离记录。所有操作符合 GLP 要求，无需进一步评估。  
本章节结论：合规。
