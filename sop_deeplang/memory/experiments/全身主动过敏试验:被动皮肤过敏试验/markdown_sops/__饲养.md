### **第一部分：核心准则**
由于提供的验证方案（Protocol）和GLP报告（Report）均为空白或无具体内容，该章节无明确的操作标准或数据处理逻辑。下游AI在生成报告时，应默认采用声明式表述，确认无偏离、无数据输入或无特殊要求，仅在有后续输入时扩展为具体计算和对比。禁止编造任何数据或标准，确保输出保持中性、简洁的合规声明。

### **第二部分：通用模板**
1. 检查输入的验证方案和报告数据是否为空。
2. 如果为空或仅为声明（如“无偏离”），使用以下模板生成报告片段：  
   “本章节[{{章节名称}}]基于验证方案[{{方案编号}}]执行，无具体数据输入或偏离。所有操作符合GLP要求。”  
3. 如果后续提供数据，提取关键变量（如{{实际值}}、{{接受标准}}），计算{{差异}} = ({{实际值}} - {{预期值}}) / {{预期值}} * 100%，并对比{{接受阈值}}（如±{{阈值}}%）。  
4. 填入结果：如果符合，声明“结果满足接受标准”；否则，记录“不符合”并说明原因。  
5. 保留计算位数为{{指定小数位}}（默认2位）。
