### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空，本 SOP 适用于无具体数据支持的章节场景。撰写时必须遵守以下规则：  
1. 确认章节标题后，检查是否存在任何偏离或数据输入；若无，则默认表述为“无偏离”或“符合预期”。  
2. 保持声明简洁、中性，不引入任何假设性数据或计算。  
3. 若未来输入包含数据，则扩展为动态描述；否则，固定输出标准化声明。  
4. 确保表述符合 GLP 原则：客观、完整、无冗余。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入的验证方案和报告数据：若为空或仅含声明（如“无偏离”），则使用模板“本章节[章节标题]无具体验证数据或偏离，符合方案预期。”  
2. 替换占位符：[章节标题] → 当前章节名称（如“系统适用性测试”）。  
3. 若有数据输入，扩展为“从附件[附件编号]提取数据，确认{{Key_Metric}}符合{{Acceptance_Criteria}}”；否则，终止扩展。  
4. 输出格式：单段落，商务语气，无额外解释。
