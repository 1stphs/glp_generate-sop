### **第一部分：核心准则**
* 该章节用于报告验证方案（Protocol）和GLP报告（Report）之间的差异分析，包括静态文本直接复制和动态数据提取的逻辑。
* 必须区分静态内容（如方案声明）和动态内容（如实际数据、日期），并确保SOP通用化处理空输入或无偏离情况。
* 在无具体数据时，输出标准化声明（如“无偏离”），避免编造信息；所有计算或对比需原子化描述步骤，但本章节为空输入时仅生成声明模板。
* 合规底线：SOP必须闭环指导AI从输入中提取差异（Delta），若Protocol和Report均为空，则声明“无差异支持数据”。

### **第二部分：通用模板**
* **指令脚本**：  
  1. 从输入的验证方案（Protocol）中提取静态文本，如接受标准或声明，使用{{Static_Declaration}}占位符直接复制。  
  2. 从GLP报告（Report）中提取动态数据，如实际结果或日期，使用{{Dynamic_Data}}占位符；若为空，填充“无具体数据”。  
  3. 比较差异：若Protocol和Report内容匹配，输出“无偏离”；否则，计算Delta（如{{Delta_Value}} = Report_Data - Protocol_Standard），并描述“差异为{{Delta_Description}}”。  
  4. 生成输出：若无数据，填入模板“本章节验证方案与报告无明确差异，符合GLP要求，无偏离。”；保留位数为报告原始精度。  
* **占位符示例**：{{Protocol_Section}} = [提取的方案文本]；{{Report_Section}} = [提取的报告文本]。
