### **第一部分：核心准则**
由于验证方案和GLP报告中无具体内容，该章节撰写时仅需声明无偏离或无数据支持。严格遵守二元差异定位：无静态文本可直接复制，无动态数据需提取。若后续输入出现数据，则需比较接受标准（如偏差阈值）与实际结果，生成合规判定；否则，默认表述为“无偏离”，确保逻辑闭环。

### **第二部分：通用模板**
1. 检查验证方案中是否有针对该章节的接受标准或数据要求。
2. 若无数据或偏离，从报告中提取声明性文本，填入以下模板：
   “本章节验证符合{{Protocol_Requirements}}要求，无{{Deviation_Type}}偏离。”
3. 若有数据，执行：从原始记录提取{{Key_Data}} -> 计算{{Calculation_Steps}}（保留2位小数） -> 对比{{Acceptance_Criteria}} -> 若符合，输出“结果{{Result}}满足要求”；若不符合，输出“存在{{Deviation_Description}}，需{{Corrective_Action}}”。
4. 结束时添加： “所有操作符合GLP规范。”

### **第三部分：报告示例**
本章节验证符合方案要求，无任何偏离。所有操作符合GLP规范。
