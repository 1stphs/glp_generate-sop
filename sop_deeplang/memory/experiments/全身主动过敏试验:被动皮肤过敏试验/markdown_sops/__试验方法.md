### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空，无法提取具体接受标准、数据变量或逻辑流程。该章节在原始材料中无明确数据支持，无法定义合规性底线或计算规则。默认准则：若无偏离或数据，则报告中仅声明“无偏离”或“未执行”，确保逻辑闭环。

### **第二部分：通用模板**
执行以下指令生成报告片段：
1. 检查附件或原始记录中是否存在 [章节相关数据]（如实验结果、偏差记录）。
2. 若无数据或偏离，填入模板：  
   “本章节验证符合方案要求，无偏离发生。”  
   或  
   “该验证未执行，[简要原因]。”  
3. 若存在数据，提取 [关键变量]（如 [Mean_Value]、[CV%]），计算 [指定公式]（保留 [位数] 位小数），并与 [接受标准] 比较。  
   - 若符合：描述为“结果满足 [接受标准]，{{Calculated_Result}} 在限值内。”  
   - 若不符合：描述为“结果 [符合/不符合] [接受标准]，实际值为 {{Actual_Value}}。”  
4. 确保输出商务语气，结构为：结果呈现 + 判定 + 数据来源引用。
