### **第一部分：核心准则**
* 鉴于验证方案（Protocol）和GLP报告（Report）中均无具体内容，该章节撰写时必须遵守声明式原则：仅报告无偏离或无数据可用情况，不引入任何假设性数据或计算逻辑。
* 动态内容处理：若未来输入存在数据，从原始记录提取并声明“无偏离”；否则，使用标准声明模板确认空章节合规性。
* 通用化要求：所有描述必须保持中性、事实导向，避免具体数值或案例细节；分支逻辑仅限于“有数据时取数声明，无数据时直接声明无偏离”。

### **第二部分：通用模板**
1. **指令执行路径**：
   - 从附件或原始记录中检查该章节相关数据（如 {{Chapter_Data}}）。
   - 若存在数据：提取关键事实（如 {{Key_Facts}}），计算或比较无偏离状态，并填入模板。
   - 若无数据：直接输出标准声明。
2. **Prompt 脚本**（供AI Generator使用）：
   ```
   针对章节 [章节名称]，从验证方案和报告中提取信息。
   - 如果有数据：报告 {{Key_Facts}}，并声明“本章节无偏离，所有操作符合GLP标准”。
   - 如果无数据：输出“该章节无具体数据记录，无偏离”。
   确保输出商务语气，结构为：事实陈述 + 合规声明。
   ```
