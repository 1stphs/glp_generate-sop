### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据支持的章节撰写。核心规则为：若无试验数据、偏离或计算结果，则报告必须以简洁声明形式呈现，确认“无偏离”或“未执行”，避免任何数据推断或假设。动态部分（如试验编号）需从上游流程提取，若无则使用通用占位符。逻辑闭环：检查输入是否为空 → 若空，直接输出声明 → 确保声明不引入未验证信息。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 从上游附件或 Master 提取章节相关元数据（如 [试验编号]、[章节标题]）。  
2. 若无具体数据或偏离记录，填充以下模板：  
   “本章节 [章节标题] 在试验 [试验编号] 中无偏离发生。所有操作严格按照方案执行，未发现任何不符合接受标准的情况。”  
3. 若存在简单元数据补充，插入占位符：  
   “根据方案要求，本章节 [章节标题] 已完成初步审查，结果符合预期（{{Compliance_Status}} = 符合）。”  
4. 输出时保持商务语气，段落不超过 2 句，无需表格或计算。

### **第三部分：报告示例**
本章节在试验 GLP-001 中无偏离发生。所有操作严格按照方案执行，未发现任何不符合接受标准的情况。
