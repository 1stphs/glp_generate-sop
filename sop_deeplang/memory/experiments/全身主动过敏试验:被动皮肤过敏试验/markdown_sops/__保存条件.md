### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据支持的章节场景。核心准则为：当章节无明确实验数据、偏离或结果时，报告必须以简洁声明形式呈现，确认“无偏离”或“无适用内容”，避免任何数据推断或计算；若未来输入数据，则需补充实际值并验证合规性（例如，差异 ≤ ±15.0% 的通用红线，但此处不适用）。逻辑闭环：检查输入是否为空 → 若空，则输出标准化声明 → 若非空，触发数据提取与对比流程。

### **第二部分：通用模板**
1. 检查章节输入：若验证方案和报告数据为空或仅含声明，则使用以下模板直接生成报告片段。
2. 填充占位符：`{{章节名称}}` 为当前章节标题；`{{试验编号}}` 为协议中试验 ID（若无，则省略）。
3. 输出指令：  
   “在 {{章节名称}} 章节中，无具体数据或偏离记录。试验 {{试验编号}} 符合预期，无偏差发生。所有操作严格按照 GLP 原则执行，无需进一步计算或验证。”

分支逻辑：若输入非空，则扩展为“从附件提取 {{变量}} → 计算 {{公式}}（保留 2 位小数）→ 对比接受标准 → 描述结果（符合/不符合）”。

### **第三部分：报告示例**
在 [章节名称] 章节中，无具体数据或偏离记录。试验 [试验编号] 符合预期，无偏差发生。所有操作严格按照 GLP 原则执行，无需进一步计算或验证。
