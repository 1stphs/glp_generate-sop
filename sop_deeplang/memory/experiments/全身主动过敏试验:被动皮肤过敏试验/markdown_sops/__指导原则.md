### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，且无具体章节名称指定，本 SOP 采用声明式通用框架。核心准则限定为：在无数据或偏离时，下游 AI 必须输出简洁声明，确认章节合规性，避免任何数据编造或假设。接受标准：仅报告“无偏离”或“未执行”状态，不引入计算逻辑或变量提取。若未来输入包含具体内容，则扩展为二元差异定位（静态文本直接复制，动态数据从附件提取）。

### **第二部分：通用模板**
执行以下指令生成报告片段：
1. 检查输入 Protocol 和 Report 是否为空。
2. 若为空或仅含声明，填入模板：  
   “本章节[{{Chapter_Name}}] 未执行具体验证或无偏离。所有操作符合 GLP 要求，无需进一步数据呈现。”  
   替换 {{Chapter_Name}} 为实际章节名称（如“稳定性测试”）。
3. 若有数据，扩展为：从 Protocol 提取静态标准（如接受阈值），从 Report 附件提取动态值（如 {{Measured_Value}}），对比后描述：若符合，声明“结果满足 {{Acceptance_Criterion}}”；若不符合，添加“偏差已记录并纠正”。
4. 结束以“本章节验证完成”。

### **第三部分：报告示例**
本章节未执行具体验证或无偏离。所有操作符合 GLP 要求，无需进一步数据呈现。本章节验证完成。
