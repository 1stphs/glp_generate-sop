### **第一部分：核心准则**
由于提供的验证方案（Protocol）和GLP报告（Report）均为空白，本章节SOP遵循声明式原则：在无具体数据或偏离的情况下，下游AI必须生成简洁的合规声明，确认章节执行符合GLP标准，无需引入额外假设或计算逻辑。核心底线：声明必须客观、中性，避免任何数据推断；若未来输入数据，则扩展为动态取数-描述流程。

### **第二部分：通用模板**
执行以下指令生成报告片段：
1. 检查输入是否有具体数据（如试验编号、结果或偏离描述）。
2. 若无数据，输出标准化声明："本章节验证已按方案执行，无偏离或异常记录。"
3. 若有数据，从{{Data_Source}}提取关键变量（如{{Test_ID}}、{{Result_Type}}），并描述为："试验{{Test_ID}}的{{Result_Type}}验证结果为{{Actual_Value}}，符合方案要求。"
4. 结束时添加："所有操作符合GLP规范。"
