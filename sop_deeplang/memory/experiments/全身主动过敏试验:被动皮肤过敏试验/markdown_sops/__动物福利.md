### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 针对无具体数据支持的章节场景。撰写时必须遵守以下规则：  
- 确认章节标题后，检查原始记录中是否存在相关数据或声明；若无任何内容，则默认报告“该章节无执行内容或偏离”，无需引入假设性数据。  
- 保持声明简洁、中性，避免任何计算或比较逻辑；仅在有明确“无偏离”或类似声明时，使用其作为基准。  
- 输出必须对齐 GLP 报告的商务格式：客观、事实性描述，不添加解释性前导语。  
- 分支处理：若后续输入出现数据，则切换至动态取数-描述流程；否则，固定输出标准化无内容声明。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 从原始记录或方案附件中检索 [章节名称] 相关内容。若为空或仅为“无执行/无偏离”，则填入模板：  
   “[章节名称]：本试验中，该章节无具体执行内容或记录，无偏离发生。”  
2. 若存在简单声明（如“符合标准”），替换为：  
   “[章节名称]：根据 [方案编号]，[具体声明，例如：无偏离]。所有操作符合 GLP 要求。”  
3. 占位符替换规则：  
   - [章节名称] → 实际章节标题（如“系统适用性”）。  
   - [方案编号] → 来自 Protocol 的编号（如“VP-001”）。  
   - [具体声明] → 直接复制输入声明，无修改。  
4. 确保输出长度不超过 50 字，排版为单段落。
