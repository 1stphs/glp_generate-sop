### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 适用于无具体数据或偏离的章节。撰写时必须遵守以下规则：  
- 声明无偏离或无数据时，使用简洁、事实性的语言，避免推测或额外解释。  
- 静态文本直接引用通用 GLP 声明（如“本章节无偏差”），动态部分（如试验编号）使用占位符填充。  
- 若未来输入数据，优先检查接受标准（如偏差阈值），但在无数据情况下，默认表述为合规状态。  
- 确保输出逻辑闭环：确认无偏差 → 简述依据 → 结束章节，无分支处理不符合情况。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入：若 Protocol 和 Report 为空或仅含声明，则使用模板填充占位符。  
2. 填充静态文本：直接插入“本章节无偏离”或类似声明。  
3. 动态插槽：替换 `[章节名称]`、`[试验编号]` 为实际值；若无数据，标记为“N/A”。  
4. 输出格式：以商务语气撰写，段落不超过 3 句。  

**模板脚本：**  
“在 [章节名称] 中，试验编号 [试验编号] 的验证过程无任何偏离。所有操作均符合 GLP 标准，无需进一步调整。{{Summary_Statement}}（若无数据，填入‘无额外数据记录’）。”

### **第三部分：报告示例**
在稳定性章节中，试验编号 GLP-001 的验证过程无任何偏离。所有操作均符合 GLP 标准，无需进一步调整。无额外数据记录。
