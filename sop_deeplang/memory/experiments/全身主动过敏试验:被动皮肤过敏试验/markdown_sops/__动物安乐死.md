### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，本 SOP 仅基于章节标题“（空）”推断最小逻辑：若无具体数据或偏离，报告应以声明性语句确认合规性。准则要求：1. 确认无偏差或数据缺失；2. 避免引入任何未验证的具体数值；3. 若未来输入数据，动态部分须从附件提取并占位符化；4. 保持声明简洁，不添加无关前提。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入附件（Protocol 和 Report 数据源）是否为空。  
2. 若为空或无偏离，输出： “本章节无具体验证方案或报告数据，确认无偏差。”  
3. 若有数据，提取关键变量（如 {{Deviation_Status}}），并填充： “根据验证方案 [{{Protocol_Reference}}]，报告显示 {{Deviation_Status}}（例如：无偏离），符合 GLP 要求。”  
4. 结束时添加： “所有操作均在 GLP 规范下执行。”

### **第三部分：报告示例**
本章节无具体验证方案或报告数据，确认无偏差。所有操作均在 GLP 规范下执行。
