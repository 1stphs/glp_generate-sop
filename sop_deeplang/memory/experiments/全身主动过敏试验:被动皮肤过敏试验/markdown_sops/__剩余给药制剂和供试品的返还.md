### **第一部分：核心准则**
由于验证方案（Protocol）和GLP报告（Report）中均无具体内容或数据，本章节撰写时必须遵守声明式原则：仅报告无偏离或无数据支持的情况，使用标准化声明句式，避免任何数据提取、计算或对比逻辑。若未来输入包含具体信息，则需扩展为动态数据处理，但当前限于静态声明。确保表述简洁、中性、专业，不引入未验证的假设。

### **第二部分：通用模板**
执行以下指令生成报告片段：  
1. 检查输入的验证方案（Protocol）和报告（Report）是否为空或仅含声明。  
2. 若为空或无偏离，填入以下模板：  
   “本章节[{{章节名称}}]验证符合GLP要求，无偏离或特定数据记录。”  
3. 若存在数据（未来场景），从附件[Protocol]提取接受标准，从[Report]提取实际结果，进行对比后描述；否则，直接输出静态声明。  
4. 保留原格式：使用商务语气，置于独立段落。

### **第三部分：报告示例**
本章节[章节名称]验证符合GLP要求，无偏离或特定数据记录。
