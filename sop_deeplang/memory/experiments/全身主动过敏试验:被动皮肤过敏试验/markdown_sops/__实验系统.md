### **第一部分：核心准则**
由于提供的验证方案 (Protocol) 和 GLP 报告 (Report) 均为空白，且无任何具体数据、接受标准或描述性内容，本章节撰写时必须遵守声明式原则：当输入材料中无明确试验细节、偏离或数据支持时，下游 AI 应输出标准化无内容声明，确认章节存在但无实质信息需报告。禁止编造任何假设性数据、标准或流程；若未来输入补充具体内容，则切换至数据驱动模式，包括提取变量、计算逻辑（如适用）和合规对比。

### **第二部分：通用模板**
1. 检查输入材料（Protocol 和 Report）：若 Protocol 和 Report 均为空或仅含标题/占位符，无需提取任何动态数据（如 {{Trial_ID}}、{{Deviation_Details}}）。
2. 生成声明文本：使用以下模板直接填充报告。
   - 模板："本章节[{{Chapter_Title}}]基于提供的验证方案和报告材料进行审查。当前输入中无具体试验细节、数据或偏离记录，因此无进一步分析或报告内容。"
3. 若输入补充数据，则扩展为："从 Protocol 提取接受标准 {{Acceptance_Criteria}}；从 Report 提取实际结果 {{Actual_Results}}；对比并描述合规性（符合/不符合），包括计算步骤（如适用）和保留位数。"
4. 结束时添加："无偏离或补充信息待报告。"
